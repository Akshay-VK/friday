# Friday

Friday is a personal control room for understanding local work and deliberately opening or running it. Its observations and your corrections remain distinct.

## Language

### Work and locations

**Project**:
A unit of work you recognize and return to, which may have several local checkouts or contain subprojects.
_Avoid_: Repo, checkout, folder as interchangeable names

**Repository**:
A Git-managed history associated with work; shared history is evidence of a relationship, not proof that two projects are identical.
_Avoid_: Project when referring specifically to Git history

**Checkout**:
A particular local working location of a repository, with its own branch, working changes, availability, and launch context.
_Avoid_: Clone when worktrees are also intended

**Subproject**:
A separately recognized unit of work within a project's workspace.
_Avoid_: Component when independent project treatment is intended

**Component**:
A detected part of a project that does not yet have independent project treatment.
_Avoid_: Subproject before promotion

**Collection**:
A grouping of projects, initially suggested by their containing folder and adjustable by you.
_Avoid_: Workspace when referring only to a group of projects

**Scan root**:
A location you have explicitly permitted Friday to observe.
_Avoid_: Drive access when only one subtree is permitted

**Folder map**:
Your annotated account of where things belong, rather than an exhaustive directory tree.
_Avoid_: File browser

### Knowledge and continuity

**Fact**:
An observation or derived claim about your work, accompanied by evidence and its age.
_Avoid_: Truth when evidence may be incomplete

**Override**:
A correction or preference you supply that takes precedence over a derived fact without changing its source.
_Avoid_: Source edit

**Evidence**:
The source and reasoning supporting a fact, including when it was observed and how certain it is.
_Avoid_: Explanation when no supporting source is available

**Freshness**:
How recently Friday successfully observed a particular source or fact.
_Avoid_: Availability, which is a different condition

**Session**:
An OpenCode conversation associated with a working location; opening it is not permission to execute an agent turn.
_Avoid_: Task, terminal

**Attention item**:
An observed condition that offers you a useful next action, not merely old or missing data.
_Avoid_: Alert for every informational change

**Observation gap**:
A period during which Friday did not observe a source and cannot establish what happened there.
_Avoid_: Uptime, downtime without supporting observations

### Actions and surfaces

**Read**:
An action that observes approved sources without changing them.
_Avoid_: Safe as a substitute for a specific permission

**Open**:
A deliberate action that opens a program or resource; the opened application may itself write data.
_Avoid_: Run when no configured work command is executed

**Run**:
A deliberate action that executes a configured command and may change files or start a process.
_Avoid_: Refresh, scan, automatic launch

**Launch profile**:
An ordered selection of targets to open for a project and checkout.
_Avoid_: Startup script

**Resume**:
Reopening the selected project's working context and optionally an existing session, without submitting input or automatically continuing execution.
_Avoid_: Continue execution

**Capture**:
Saving a task or note into Friday's own records.
_Avoid_: Source modification

**Away inbox**:
The review surface for requests and observed changes received or discovered after an absence.
_Avoid_: History of everything that happened while the laptop was off

**Panel**:
A configurable presentation of a particular source or kind of information within Friday.
_Avoid_: Plugin when only configuration is involved

**View**:
A named arrangement of panels for a purpose such as Home or Photography.
_Avoid_: Panel when referring to the whole arrangement

**Shoot**:
A suggested grouping of photographs taken near one another in time, which does not rearrange the originals.
_Avoid_: Album when no user-curated collection exists
